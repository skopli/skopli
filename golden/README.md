# Golden conformance corpus

This directory is the behavioral contract of skopli. Every case
pairs real-shaped input files (`input/`, plus `input-manifest.json` describing
the home/env wiring) with the exact expected outputs (`expected-*.json`,
structural equality, exact float semantics). The Rust core replays every case
in `crates/skopli-core/tests/conformance.rs` and
`tests/pricing_conformance.rs`.

## Provenance

The corpus was generated by the original TypeScript implementation of
skopli — the battle-tested pre-port code. Its final working state
(readers, case definitions, exporter) was verified zero-drift
(byte-identical double run) immediately before it was retired.

The TypeScript implementation was deliberately retired rather
than kept as a live oracle: for new third-party format changes, both
implementations would be written by the same maintainer from the same samples,
so a sibling implementation provides correlated guesses, not independence.
The ground truth for this domain is the third-party applications' real files
and their own reported numbers. Prior art: Turborepo (Go code deleted,
vercel/turborepo#6956), fish-shell's riir plan, ruff, oxc, Biome - all kept
the predecessor's test artifacts and deleted its code.

## Updating the corpus

Git is the change control: any edit to a gold file shows up in the diff and
should be reviewed like code. Guidelines:

- **Changing an existing `expected-*.json`** means changing documented
  behavior; say why in the commit message.
- **New cases** (new formats or format changes): prefer `input/` files
  captured from the real application (sanitized) over synthesized ones.
  Expected outputs may be generated by the Rust implementation — review the
  numbers before committing, ideally spot-checking a headline figure (total
  cost, token count) against the source application's own UI.

## Layout

```
golden/<harness>/<case>/
  input-manifest.json   # home/env wiring for the case
  input/...             # real-shaped source files (incl. SQLite .db binaries)
  expected-events.json  # exact expected usage events
  expected-rollup.json  # exact expected rollup
golden/pricing/         # pricing engine cases + vendored catalogs
```
