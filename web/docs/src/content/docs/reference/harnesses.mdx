Skopli reads the session state each harness already writes to disk. Nothing is installed into the harness: no plugin, no proxy, no exporter. Pass the `id` column to `readUsage({ harnesses })` to restrict a read; the full `detectHarnesses()` result lists which of these have local data on the current machine.

## Detected but not parsed

`detectHarnesses()` reports these four under `unsupported` when their state directories exist, so you know the data is there even though Skopli does not read it yet: Cursor, aider, Crush, GitLab Duo CLI.

## Adding a harness

Each harness is a parser in the Rust core with golden fixtures under `golden/`. The registry at `golden/registry/ids.json` is the single list of ids; the docs render a hand-maintained copy of it from the shared `@skopli/ui` package, and a test asserts that copy equals the registry.
