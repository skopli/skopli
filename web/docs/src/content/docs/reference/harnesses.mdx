## Notes by harness

- **Kiro CLI** stores no token counts, so its events carry estimated tokens.
- **Reasonix** is read from its `stats/` ledger, one event per request, keyed by the ledger's day rather than a session.
  A home without that ledger (builds before it existed) falls back to the per-session sidecars, one event per session.
- **fx** logs one event per model per session, so `turns` and per-message detail are not available for it.
- **Trae Agent** writes local wall-clock timestamps with no offset.
  The reader recovers the offset from each trajectory's file mtime when the two agree to within ten minutes of a quarter-hour; otherwise it books the timestamps as UTC and reports a warning for the file.
- **Codex CLI, Grok Build and ZCode** report reasoning inside output.
  The reader subtracts it so the buckets stay disjoint.
- **GitHub Copilot CLI** is read from its session-state logs.
  Records from its optional OTel file exporter are kept only for sessions the session-state logs do not know, so a request is never counted twice.
  The OTel conventions do not state whether output includes reasoning, so for those records the two are treated as disjoint and not subtracted.
- **Claude Code** reports the 5m/1h cache-write split, which populates `tokens.cacheWrite1h`, and records `costUSD`, which populates `costUsd`.
- **OpenCode** supplies `workspace`, `title` and, when non-zero, `costUsd`.
- **Hermes Agent** reports a per-row `message_count`, which populates `calls`.
- **OpenCode, ZCode, Devin CLI and Cline** keep both a SQLite store and a legacy JSONL mirror.
  The SQLite store is authoritative and the mirror is not double-counted.

## Subagent markers

| Harness                  | Marker                 |
| ------------------------ | ---------------------- |
| OpenCode                 | non-null `parent_id`   |
| Claude Code              | `isSidechain === true` |
| Pi, omp                  | `rlmDepth > 0`         |
| Codex CLI and all others | always `false`         |

## Detected but unsupported

Cursor, aider, Crush and GitLab Duo CLI are recognized by `detectHarnesses()` and returned in `unsupported`.
They keep no reliable local token data, so Skopli reports their presence and nothing else.
