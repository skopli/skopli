---
title: Model matching
description: The ordered set of keys Skopli tries when looking a model name up in a catalog, and why a miss is a miss.
---

Harnesses name models in their own ways: `gpt-5`, `openai/gpt-5`, `claude-sonnet-4-5-20250929`, `us.anthropic.claude-opus-4-6-20260115-v1:0`.
Catalogs key them differently again.
`candidateKeys(model)` produces the list of keys Skopli tries, in decreasing confidence, and `lookupModel` walks it against each catalog.

## The ladder

1. **Exact name.** `gpt-5` matches `gpt-5`.
2. **Prefix strip.** Each shorter suffix of a slash-separated path: `openai/gpt-5` tries `gpt-5`. Vendor route prefixes are stripped too: `us.anthropic.claude-...` tries `anthropic.claude-...` (also `eu.`, `apac.`, `global.`).
3. **Family aliases.** Patterns that reduce a vendor-decorated name to its family: Bedrock's `anthropic.claude-sonnet-4-5-20250929-v1:0` becomes `claude-sonnet-4.5`. Platforms that resell a model line under their own route name reduce the same way, so such names price as the underlying model.
4. **Separator and date normalization.** `claude-sonnet-4.5`, `claude-sonnet-4-5` and `claude-sonnet-4-5-20250929` are tried as one family.
5. **Provider-prefixed family forms.** OpenRouter keys Claude models as `anthropic/claude-*`, so `claude-opus-4.6` also tries `anthropic/claude-opus-4.6`.
6. **Alias table.** A hand-maintained map for names the mechanical rules miss.

The `key` on a hit tells you which rung matched.
In the repository's golden fixture, `us.anthropic.claude-opus-4-6-20260115-v1:0` prices through OpenRouter under `anthropic/claude-opus-4.6`.

## Misses

If no rung matches in any catalog, the result is `{ priced: false, model, attempted }` where `attempted` is the full list of keys tried.
Nothing is estimated from a similar-looking name.

Zero-cost catalog entries are skipped as placeholders so a later source can still match.
When the only matches were zero-cost, the miss is `{ priced: false, reason: "zeroCost", key }`.
Set an explicit `{ model, input: 0, output: 0 }` in `overrides` if $0 is the truth for a model you host yourself.
Overrides are never treated as placeholders.

## Inspecting candidates

`candidateKeys` is exposed by the TypeScript package and the Rust core.
The other facades return the tried keys in the miss result as `attempted`.

```ts
import { candidateKeys } from "skopli";

candidateKeys("us.anthropic.claude-opus-4-6-20260115-v1:0");
```

Use this when a model you expected to price comes back as a miss: compare the output against the catalog's keys and add an override or report the gap.
