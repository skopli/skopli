## Install

| Language   | Install                                                             |
| ---------- | ------------------------------------------------------------------- |
| TypeScript | `pnpm add skopli` (also `npm install skopli`, `bun add skopli`)     |
| Python     | `pip install skopli`                                                |
| Rust       | `cargo add skopli-core`                                             |
| Ruby       | `gem install skopli`                                                |
| Java       | `com.skopli:skopli` on Maven Central                                |
| C#         | `dotnet add package Skopli`                                         |
| Go         | `go get github.com/skopli/skopli/sdks/go`                           |
| Swift      | `.package(url: "https://github.com/skopli/skopli", branch: "main")` |
| C          | Prebuilt `libskopli` and `skopli.h` from GitHub Releases            |

The TypeScript package is ESM only and needs Node 24 or later.
The Go, Java, C# and Swift facades load the native `skopli` library.
Their READMEs in the repository describe where each runtime looks for it.

```ts
import { detectHarnesses, readUsage, rollup, createPricing } from "skopli";

const { supported, unsupported } = detectHarnesses();
console.log(supported, unsupported);

const { events, diagnostics } = await readUsage({
  harnesses: ["claude", "opencode", "codex"],
  since: "2026-08-01",
});

const byModel = rollup(events, { by: "model" });

const pricing = createPricing();
const priced = await pricing.priceRollups(byModel);

for (const row of priced) {
  if (row.pricing.priced) {
    console.log(row.key, row.pricing.usd, row.pricing.source);
  } else {
    console.log(row.key, "unpriced, tried", row.pricing.attempted);
  }
}
```

use skopli_core::pricing::types::PricingCatalog;
use skopli_core::pricing::{Pricing, PricingMode};
use skopli_core::rollup::{rollup, RollupBy, RollupOptions};

<Fragment slot="go">

```go
import "github.com/skopli/skopli/sdks/go/skopli"

func priceByModel() ([]skopli.PricedRollup, error) {
	usage, err := skopli.ReadUsage(skopli.ReadUsageOptions{Since: "2026-08-01"})
	if err != nil {
		return nil, err
	}
	opts := skopli.RollupOptions{By: skopli.ByModel}
	byModel, err := skopli.Rollup(usage.Events, opts)
	if err != nil {
		return nil, err
	}
	pricing, err := skopli.NewPricing(skopli.PricingOptions{})
	if err != nil {
		return nil, err
	}
	defer pricing.Close()
	return pricing.PriceRollups(byModel)
}
```

<Fragment slot="c">

```c
#include "skopli.h"

// Every call takes and returns JSON. Free each AgBuf with ag_buf_free.
// The prebuilt library has no network layer, so pass a catalog you fetched.
const char *read_opts = "{\"since\":\"2026-08-01\"}";
AgBuf usage = {0};
if (ag_read_usage(read_opts, strlen(read_opts), &usage) != AG_STATUS_OK)
  return 1;

const char *rollup_opts = "{\"by\":\"model\"}";
AgBuf by_model = {0};
if (ag_rollup((const char *)usage.ptr, usage.len, rollup_opts,
              strlen(rollup_opts), &by_model) != AG_STATUS_OK)
  return 1;

const char *pricing_opts =
    "{\"builtinSources\":false,\"catalogs\":[{\"source\":\"litellm\","
    "\"format\":\"litellm\",\"payload\":" LITELLM_JSON "}]}";
AgPricing *pricing = NULL;
if (ag_pricing_new(pricing_opts, strlen(pricing_opts), &pricing)
    != AG_STATUS_OK)
  return 1;

AgBuf priced = {0};
ag_pricing_price_rollups(pricing, (const char *)by_model.ptr, by_model.len,
                         &priced);

ag_pricing_free(pricing);
ag_buf_free(priced);
ag_buf_free(by_model);
ag_buf_free(usage);
```

Reading and rolling up never touch the network.
`createPricing()` fetches the OpenRouter, LiteLLM and models.dev catalogs the first time it needs them, caches them on disk for about an hour, and keeps using the cache when a fetch fails.
Pass `offline: true` or `sources: []` to price without any network access.
The Rust core crate and the bare C library have no fetch layer at all, so they take catalogs you supply.
[Pricing basics](/skopli/guide/pricing-basics/) has the details.

## What comes back

A priced rollup carries the summed tokens, the number of events, turns and model calls, and a `pricing` object.
When a model matched a catalog, `pricing.priced` is `true` and you get `usd`, the catalog `key` that matched, the `source` and its `fetchedAt` timestamp.
When no catalog knows the model, `pricing.priced` is `false` and `attempted` lists every key that was tried.
Skopli never substitutes a guessed price.
