## Install

| Language   | Install                                                          |
| ---------- | ---------------------------------------------------------------- |
| TypeScript | `pnpm add skopli` (also `npm install skopli`, `bun add skopli`)  |
| Python     | `pip install skopli`                                             |
| Rust       | `cargo add skopli-core`                                          |
| Ruby       | `gem install skopli`                                             |
| Java       | `com.skopli:skopli` on Maven Central                             |
| C#         | `dotnet add package Skopli`                                      |
| Go         | `go get github.com/skopli/skopli/sdks/go`                        |
| Swift      | `.package(url: "https://github.com/skopli/skopli", from: "...")` |
| C          | Prebuilt `libskopli` and `skopli.h` from GitHub Releases         |

The TypeScript package is ESM only and needs Node 24 or later.
The Go, Java, C# and Swift facades load the native `skopli` library; their READMEs in the repository describe where each runtime looks for it.

## Read, roll up, price

```ts
import { detectHarnesses, readUsage, rollup, createPricing } from "skopli";

const { supported, unsupported } = detectHarnesses();

const { events, diagnostics } = await readUsage({
harnesses: ["claude", "opencode", "codex"],
since: "2026-08-01",
});

const byModel = rollup(events, { by: "model" });

const pricing = createPricing();
const priced = await pricing.priceRollups(byModel);

for (const row of priced) {
if (row.pricing.priced) console.log(row.key, row.pricing.usd, row.pricing.source);
else console.log(row.key, "unpriced, tried", row.pricing.attempted);
}

````

The first two steps never touch the network.
`createPricing()` fetches the OpenRouter, LiteLLM and models.dev catalogs the first time it needs them, caches them on disk for about an hour, and keeps using the cache when a fetch fails.
Pass `offline: true` or `sources: []` to price without any network access; see [Pricing basics](/skopli/guide/pricing-basics/).

## What comes back

A priced rollup carries the summed tokens, the number of events, turns and model calls, and a `pricing` object.
When a model matched a catalog, `pricing.priced` is `true` and you get `usd`, the catalog `key` that matched, the `source` and its `fetchedAt` timestamp.
When no catalog knows the model, `pricing.priced` is `false` and `attempted` lists every key that was tried.
Skopli never substitutes a guessed price.
