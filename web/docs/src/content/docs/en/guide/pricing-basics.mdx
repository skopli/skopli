The Price layer matches models against market catalogs and computes USD costs. It is the only layer that touches the network. By default it fetches the market catalogs the first time you price, caches them on disk, and keeps pricing from that cache when offline. Pass an empty `sources` list or `offline: true` for a network-free handle. Prices are USD per million tokens.

The seven handle-based facades (TypeScript, Python, Ruby, Java, C#, Go, Swift) run the same lifecycle. Built-in sources are on by default in priority order OpenRouter, LiteLLM, then models.dev, unless you pass your own `sources`.

An empty `sources` list disables every built-in source. The spelling follows the language: `sources: []` in TypeScript, Ruby, and Swift, `sources=[]` in Python, an empty `sources(...)` in Java, `Sources = []` in C#, and an empty `Sources` in Go.

In the four FFI facades (Java, C#, Go, Swift) the fetch and cache run in the host language, since the embedded `libskopli` opens no socket by default. The results match the direct-core facades.

The bare C ABI has no host-language lifecycle. The default `libskopli` prices only against the `catalogs` (or `overrides`) you inject into `ag_pricing_new`, fetches nothing, and keeps no cache. The optional `net` build (`libskopli-full`) turns built-in sources on and runs the fetch, TTL cache, refresh, offline, and stale-fallback lifecycle inside Rust.

    `skopli-core` has no `create_pricing` facade. Build a `Pricing` from injected catalogs and call its methods, with `cost_usd` as a free function:

    use skopli_core::pricing::{
        cost_usd, ModelPrice, PriceLookup, Pricing, PricingMode,
    };
    use skopli_core::types::TokenCounts;

    // catalogs: Vec<PricingCatalog> in priority order; None = no override
    // catalog
    let pricing = Pricing::new(catalogs, None, PricingMode::Calculate);

    // match a model name against the injected catalogs (see the tier ladder)
    // PriceLookup::Hit | Miss
    let lookup = pricing.lookup_model("openai/gpt-5");
    let _ = matches!(lookup, PriceLookup::Hit(_));

    // price a token bundle at a flat rate (USD per million tokens)
    let tokens = TokenCounts {
        input: 1_000,
        output: 500,
        ..Default::default()
    };
    let usd = cost_usd(&tokens, &ModelPrice::flat(1.25, 10.0));

  <Tab label="C">
    The C ABI exchanges JSON buffers. The default library fetches nothing, so the options carry a catalog you fetched yourself (here the raw OpenRouter `/models` JSON). Create a pricing handle from that options JSON, price an event array, then free the handle and buffer:

    ```c
    #include <stdio.h>
    #include <stdlib.h>
    #include <string.h>
    #include "skopli.h"

    // openrouter_json holds the raw OpenRouter /models response.
    const char *head = "{\"builtinSources\":false,\"catalogs\":[{"
                       "\"source\":\"openrouter\",\"format\":\"openrouter\","
                       "\"payload\":";
    char *opts = malloc(strlen(head) + strlen(openrouter_json) + 4);
    size_t len = (size_t)sprintf(opts, "%s%s}]}", head, openrouter_json);
    AgPricing *pricing = NULL;
    ag_pricing_new(opts, len, &pricing);

    // events_json / events_len are a serialized UsageEvent[] from
    // ag_read_usage.
    AgBuf out = {0};
    const char *group = "{\"by\":\"model\"}";
    AgStatus st = ag_pricing_price_events(
        pricing, events_json, events_len, group, strlen(group), &out);
    if (st == AG_STATUS_OK) {
        // PricedEventGroup[] as JSON
        fwrite(out.ptr, 1, out.len, stdout);
        ag_buf_free(out);
    }
    ag_pricing_free(pricing);
    free(opts);
    ```

## How a model matches a price

Model names resolve to a catalog price through a tier ladder (exact key, provider-prefix strip, family aliases, separator and date normalization, provider-prefixed family forms, alias table). An unmatched model returns `{ priced: false, attempted: [...] }`.

See [Model matching](/skopli/pricing/model-matching) for the full ladder, zero-cost handling, and source priority.

## How costs are computed

Reasoning tokens bill at the output rate, token buckets are disjoint, and Claude's 5-minute and 1-hour cache writes each bill at their own rate.

See [Price tokens and cache writes](/skopli/pricing/cost-math) for the base math and a worked cache-write example.

## Long-context tiers

Long-context tier rates (128k to 512k boundaries, LiteLLM catalog) are selected per request, with marginal billing by default and whole-request repricing for Anthropic models.

See [Long-context tiers](/skopli/pricing/long-context-tiers) for the tier boundaries and how they compose with cache writes.

## Price rollups or raw events

`priceRollups` prices summed rollups, exact for flat-rate models. `priceEvents` prices each event at its own context, which is the correct path for tiered models.

See [Price rollups or raw events](/skopli/pricing/rollups-vs-events) for when each is safe.

## Cost modes

There are three cost modes. `calculate` (default) recomputes from tokens × rates, `display` reports the harness-recorded cost, and `auto` prefers recorded and falls back to calculated.

## Offline and cache

Each catalog caches on disk (default 1 hour TTL, atomic writes) under `cacheDir`, which defaults to the platform cache directory. Every facade resolves the same `defaultCacheDir` and writes the same byte-compatible `pricing-<source>.json` files, so a cache written by one facade is read by any other.

Skopli uses a cached source at any age when a fetch fails or `offline` is set, so pricing keeps working offline.

`refresh` attempts one fresh fetch per source, bypassing a fresh cache and falling back to stale on failure. It is one-shot and applies only to the first load. A long-lived handle reloads its sources once the in-memory TTL window elapses, so a later query picks up refreshed prices. `pricing.catalogs()` reports what loaded (source, `fetchedAt`, model count).
